## Decisions that differ from SPEC
- Yearly heads: charged once per enrollment in the first posting run on/after joining. Once heads: same, only on the student's first enrollment (not again after promotion)
- Plan discounts are applied inside the charge (charge = net amount, note "Plan: 20%"); a 100% plan posts nothing
- ADV head is reserved: cannot be created twice, deleted, renamed or given a fee amount; leftover payment → ADV entry in the current period
- Existing advance credit is NOT auto-applied to later charges; it shows as credit and lowers the total balance
- Receipt page size is set by JS before printing (`size: 80mm auto` is invalid CSS and ignored): 80 mm × measured height; A4 portrait 10 mm margins
- POST /fee-structures and POST /fee-plans are upserts (grid saves cell by cell); no PUT
- @nestjs/schedule pinned to v6 (v12 targets Nest 12, ESM-only)
- AccessService.displayNames() added so fees never reads user tables directly
